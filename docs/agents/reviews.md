# Reviews

- Base repository claims on inspected code, tests, configuration, current state, and useful history. Cite exact evidence when it matters.
- For third-party behavior, use official primary sources that match the installed version. Use current guidance for upgrades and new work, and report conflicts.
- Enumerate the relevant scope, then prioritize findings by user impact and risk.
- For each finding, explain the concrete failure or maintenance cost and give a safe path forward.
- Omit generic, cosmetic, or tool-generated findings that do not require judgment.
