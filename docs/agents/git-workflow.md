# Git workflow

For tasks that change files:

1. Run `git status`. Preserve existing work.
2. Change and stage only files for the task.
3. Review the diff and run checks that fit the change.
4. Commit on `main` with a short message.
5. Report the commit hash.

Push, amend, or rewrite history only when the user asks.

For read-only tasks, report the result and do not commit.
